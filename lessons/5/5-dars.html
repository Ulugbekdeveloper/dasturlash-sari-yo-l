Sahifangiz endi gapiradi va tinglaydi, lekin hamon oq qog'ozga qora harf bilan yozilgandek ko'rinadi. Bugun unga rang, shrift va shakl beramiz. Buning uchun yangi til o'rganamiz — CSS.

Nega sahifani ikki ustunga bo'lish uchun jadval ishlatilmaydi?

Javobni ko'rish

Jadval faqat jadvalli ma'lumot uchun. Ko'rinish va joylashuvni CSS boshqaradi. Bugun aynan shu CSS bilan tanishamiz.

CSS — Cascading Style Sheets, "kaskadli uslublar jadvali". U sahifaning ko'rinishini boshqaradi: rang, shrift, o'lcham, bo'shliq, joylashuv. HTML esa sahifada nima borligini aytadi: sarlavha, matn, rasm, forma.

HTML"Bu — sarlavha. Bu — paragraf. Bu — tugma."Ma'no va tuzilish.
CSS"Sarlavha to'q sariq va katta bo'lsin. Tugmaning burchaklari yumaloq bo'lsin."Ko'rinish.

Sinab ko'ring: pastdagi sahifaning HTML kodi o'zgarmaydi. Tugma faqat CSS'ni yoqadi yoki o'chiradi.

2-qism

CSS qanday yoziladi

Qoida, uni sahifaga ulash va kerakli elementni tanlash.

CSS qoidalardan (rule) iborat. Har bir qoida ikki qismdan tuziladi: kimga va nima.

h1 {
  color: orange;
  font-size: 40px;
}
h1Selektor (selector) — qoida kimga tegishli. Bu yerda: sahifadagi hamma h1 larga.
colorXususiyat (property) — nimani o'zgartiramiz: rangni.
orangeQiymat (value) — qanday qilamiz: to'q sariq.

Yozilish qoidalari juda qat'iy, ularni yodlab oling:

  • Xususiyatlar jingalak qavslar { } ichida yoziladi.
  • Xususiyat va qiymat orasida — ikki nuqta :.
  • Har bir qatordan keyin — nuqtali vergul ;.
  • Izoh: /* bu izoh */. Brauzer uni o'qimaydi, xuddi HTML'dagi <!-- --> kabi.
Eng ko'p uchraydigan xatoBitta ; yoki } tushib qolsa, brauzer xato bermaydi — u shunchaki o'sha qoidani (ba'zan keyingisini ham) jimgina e'tiborsiz qoldiradi. "CSS ishlamayapti" desangiz, avval tinish belgilarini tekshiring.
CSS tarixi · Hokon hikoya qiladi1994-yil 10-oktabrda men "Cascading HTML style sheets" degan qisqa taklifni e'lon qildim. Uslub g'oyasi yangi emas edi — Timning birinchi brauzerida ham oddiy uslublar bor edi. Lekin men shunday til xohladim: sodda, odam o'qiy oladigan va bitta sahifaga bir nechta manbadan uslub kelishiga ruxsat beradigan. Tez orada Gollandiyalik Bert Bos menga qo'shildi. U o'zining Argo brauzeri uchun uslub tili yozayotgan edi. Biz kuchlarni birlashtirdik va CSS'ning bugungi sintaksisi shu hamkorlikdan chiqdi.

Birinchi yo'l — style atributi. Uslub to'g'ridan-to'g'ri tegning ichiga yoziladi. Faqat shu bitta elementga ta'sir qiladi.

<p style="color: green;">Yashil matn</p>

Ikkinchi yo'l — <style> tegi. Qoidalar sahifaning <head> qismiga yoziladi. Butun sahifaga ta'sir qiladi.

<head>
  <style>
    p { color: green; }
  </style>
</head>

Uchinchi yo'l — alohida fayl. Qoidalar style.css faylida turadi, sahifa esa unga <link> tegi bilan ulanadi.

<head>
  <link rel="stylesheet" href="style.css">
</head>
style atributiTez sinab ko'rish uchun qulay.Lekin 50 ta sahifada 50 marta yozasiz.
style.css fayliBitta fayl — hamma sahifalar uchun.Rangni bir joyda o'zgartirsangiz, butun sayt o'zgaradi.
Ustoz maslahatiHaqiqiy loyihalarda deyarli doim uchinchi yo'l ishlatiladi. Brauzer style.css ni bir marta yuklab, eslab qoladi (keshlaydi) va keyingi sahifalarda qayta yuklamaydi — sayt tezroq ochiladi.

Selektor qoida kimga tegishli ekanini aytadi. Eng ko'p ishlatiladigan uch turi:

p { color: gray; }          /* hamma paragraflar */
.narx { color: green; }     /* class="narx" bo'lganlar */
#asosiy { color: red; }     /* id="asosiy" bo'lgan bitta element */
<p>Oddiy paragraf</p>
<p class="narx">35 000 so'm</p>
<p class="narx">12 000 so'm</p>
<p id="asosiy">Bugungi taklif!</p>
  • Teg selektori — p: sahifadagi barcha shunday teglar.
  • Class selektori — oldida nuqta: .narx. Bitta class'ni istalgancha elementga berish mumkin.
  • Id selektori — oldida panjara: #asosiy. 4-darsdan eslang: id sahifada yagona bo'ladi.

Class — familiyaga o'xshaydi: bir oilada ko'p odam bir xil familiyada. Id esa pasport raqami: faqat bitta odamda.

Ikki yangi teg. Ba'zan bir nechta elementni bitta "quti"ga solib, unga uslub berish kerak. Buning uchun ma'nosi yo'q, faqat guruhlash uchun mo'ljallangan ikki teg bor:

  • <div> — katta quti, yangi qatordan boshlanadi. Masalan, mahsulot kartochkasi.
  • <span> — matn ichidagi kichik bo'lak. Masalan, gapdagi bitta so'zni bo'yash.
<div class="karta">
  <h3>Osh</h3>
  <p>Narxi: <span class="narx">35 000 so'm</span></p>
</div>

Bitta elementga bir nechta qoida tegishli bo'lishi mumkin. Masalan, paragraf ham p, ham .narx. Ular turli rang aytsa, brauzer bitta qarorga keladi. Bu tartib kaskad (cascade — "sharshara") deyiladi.

  • Aniqroq selektor yutadi. #id kuchliroq .class dan, u esa kuchliroq teg selektoridan.
  • Kuchi teng bo'lsa — keyin yozilgani yutadi. Pastdagi qoida yuqoridagini "bosib" ketadi.
  • style atributi ularning hammasidan kuchli.
p { color: gray; }
.narx { color: green; }
p { color: blue; }

<p class="narx">35 000 so'm</p>
Matn qaysi rangda chiqadi?

Yashil. Ikkinchi p qoidasi birinchisini bosib ketdi (ko'k), lekin .narx teg selektoridan aniqroq, shuning uchun u yutadi.

CSS tarixi · Hokon hikoya qiladiNomimizdagi eng muhim so'z — "kaskad". Men shunday dunyoni xohlardim: sahifaga muallif ham, brauzer ham, hatto o'quvchining o'zi ham uslub bera olsin. Masalan, ko'zi zaif odam brauzerida "hamma matn katta bo'lsin" deb yozib qo'yadi va bu har bir saytda ishlaydi. Uslublar sharshara kabi bir-birining ustiga tushadi, aniq qoidalar esa kimning so'zi o'tishini hal qiladi. CSS1 1996-yil dekabrda rasmiy standart bo'ldi. Uni birinchi qo'llab-quvvatlagan tijoriy brauzer o'sha yili chiqqan Internet Explorer 3 edi.

3-qism

Rang, matn va quti

Har kuni ishlatiladigan xususiyatlar.

  • color — matn rangi.
  • background-color — fon rangi.

Rangni uch xil yozish mumkin:

  • Nomi bilan: red, orange, navy. Brauzer 140 dan ortiq inglizcha rang nomini biladi.
  • Hex kod bilan: #F0B429. Panjaradan keyin uch juft belgi: qizil, yashil, ko'k.
  • rgb() bilan: rgb(240, 180, 41) — o'sha uch rang, oddiy sonlarda.

Har bir rang qismi 0 dan 255 gacha. Tanish sonmi? Bu — bir bayt, 1-bobdagi sakkizta kalit! Ekrandagi har bir nuqta uch bayt: qancha qizil, qancha yashil, qancha ko'k chiroq yonishini aytadi.

Salom, dunyo!Bu matn siz tanlagan ranglarda.

Birinchi taassurot

        
Kutish ro'yxati sahifangiz bor. Endi uni odamlar bir qarashda tushunadigan va ishonadigan qilamiz.

      


      
      

        
        

          
Odam yangi saytga kirganda bir necha soniya ichida qaror qiladi: qolamanmi yoki yopamanmi? Bu vaqtda u matnni o'qimaydi — u ko'rinishga qaraydi. Tartibsiz, o'nta rangli sahifa "bu jiddiy emas" deydi.

          
Boshlovchi uchun eng xavfsiz qoida — kam narsa:

          
    
            
  • Bitta asosiy rang — tugma va muhim joylar uchun.
    • 
            
  • Bitta neytral rang — matn uchun (qora yoki to'q kulrang) va och fon.
    • 
            
  • Bitta shrift — butun sayt uchun. Sarlavhani qalinligi va o'lchami bilan ajrating, boshqa shrift bilan emas.
    •
